# Kitty

A budget tracker that tells you what's safe to spend today. Bills and savings are set aside on payday, and what's left is shared out over the days until the next one.

Installable on Android: open https://khalifa996.github.io/kitty in Chrome, then ⋮ → Add to home screen → Install.

Your data stays on your phone (browser storage). Use Settings → Copy backup now and then.
